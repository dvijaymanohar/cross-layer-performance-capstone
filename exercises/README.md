# Capstone exercises

Choose one real workload from the CUDA profiling, inference runtime, serving, or PyTorch repositories.

Required controlled experiments: at least three relevant choices such as memory layout, pinned/pageable transfer, sync/async transfer, fusion, batch/concurrency, precision, provider/runtime, queue/admission control, or compiler/runtime setting.

For each: hypothesis, independent variable, controls, expected mechanism, result, profiler evidence, correctness impact, and trade-off.
