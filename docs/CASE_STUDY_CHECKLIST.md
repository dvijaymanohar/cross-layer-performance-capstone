# Capstone checklist

- [ ] workload and success metric selected
- [ ] benchmark contract written
- [ ] trusted baseline captured
- [ ] performance problem/regression reproduced
- [ ] application/system timeline profiled
- [ ] limiting layer localized
- [ ] at least two competing hypotheses recorded
- [ ] evidence collected to distinguish them
- [ ] one focused optimization implemented
- [ ] re-benchmark and re-profile complete
- [ ] correctness/model quality validated
- [ ] stress/soak/boundary tests run where relevant
- [ ] trade-offs and rollback conditions documented
- [ ] before/after results linked to raw evidence
- [ ] interview-ready narrative written
